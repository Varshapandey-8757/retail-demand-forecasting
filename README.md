# Retail Demand Forecasting & Inventory Optimization

## Project Overview

An analytics platform that forecasts retail product demand
and generates inventory replenishment recommendations.

## Technology Stack

- Python
- SQL
- Google BigQuery
- dbt
- Prophet and LightGBM
- FastAPI
- Streamlit
